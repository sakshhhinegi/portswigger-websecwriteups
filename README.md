# PortSwigger Web Security Writeups

This repository contains my practical work and writeups from the PortSwigger Web Security Academy.

I am using these labs to build a stronger understanding of web application security by going beyond just solving the labs. My goal is to understand how vulnerabilities work, how they can be identified and exploited, why they occur, and how they can be properly mitigated.

## My Goal

I am currently building my skills toward a career in cybersecurity, with a particular interest in Web Application Security and Bug Hunting.

Through these labs, I am focusing on:

- Understanding common web application vulnerabilities
- Improving my HTTP and web application fundamentals
- Getting more comfortable with Burp Suite
- Learning to analyze requests and responses
- Developing a structured approach to vulnerability discovery
- Practicing technical security documentation and report writing
- Connecting theory with practical exploitation

## How I Document My Work

I don't want this repository to be just a collection of solved labs.

Where possible, my writeups focus on:

1. Understanding the application's behavior
2. Identifying the vulnerability
3. Explaining my reasoning and testing process
4. Analyzing the relevant HTTP requests and responses
5. Demonstrating the exploitation
6. Understanding the root cause
7. Discussing the potential impact
8. Considering appropriate remediation
9. Recording the key lessons learned
